# Markdown Editor for Bitrix

MDX-редактор на React + TypeScript + Vite для интеграции с Bitrix24.

## Возможности

- Редактирование MDX с кастомными JSX-компонентами
- Вставка фото, цитат, слайдеров, видео (VK, Rutube)
- Drag-and-drop для перестановки блоков
- Интеграция с Bitrix через глобальный API

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Стек

- React 18
- Vite 4
- [@mdxeditor/editor](https://mdxeditor.dev/)
- @dnd-kit / react-dnd
